# QACraft

QACraft is a reusable QA skill distribution and deterministic behavior-evaluation toolkit for AI coding agents.

## What QACraft provides

- Preview-first installation, verification, safe update, rollback, and uninstall.
- Verified project adapters for Codex, Claude Code, GitHub Copilot, Gemini CLI, and OpenCode.
- Generic export support for integrations that load Agent Skills independently.
- Deterministic, local, read-only evaluation for ten QA workflows.
- Verified editable, wheel, and source-distribution installation modes.
